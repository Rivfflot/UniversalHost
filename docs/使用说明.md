# UniversalHost 使用说明

本说明面向上位机操作人员。文中的“设备 > 连接设备”表示先打开“设备”菜单，再选择“连接设备”。在程序中可通过“关于 > 使用说明”打开本说明，通过“关于 > 快捷键”查看键鼠操作。

## 1. 开始前准备

- 准备设备提供方给出的通信参数、设备 ID，以及与设备当前固件匹配的符号文件（.elf、.axf 或 .out）。符号文件用于查找监控和标定变量。
- 如需在线升级，另备适用于目标设备的 .bin 文件。符号文件不能代替升级文件。
- 确认设备支持本上位机使用的通信方式。UDP 和全双工串口可用于连接、监控及标定；半双工串口只用于在线升级。
- 参数下发和在线升级会改变设备状态。操作前核对目标设备、变量或升级文件，并按现场要求确认设备允许执行相应操作。

## 2. 第一次监控

1. 启动程序，选择“文件 > 新建”，创建并保存工程；已有工程可选择“文件 > 打开”。
2. 打开“设置 > 设备”，选择通信模式，填写设备 ID，点击“添加固件”选择匹配的符号文件。
3. 打开“设置 > 通信”，按设备提供方给出的参数设置 UDP 或串口。
4. 选择“监控 > 监控设置”，在“符号表”中搜索变量并点击加号；切换到“监控变量”，核对类型和“偏移 / 下标”，勾选“是否监控”。
5. 选择“监控 > 新建表格监控窗口”或“新建曲线监控窗口”，点击窗口内加号，勾选要显示的变量。
6. 选择“设备 > 连接设备”，等待连接成功通知，再选择“监控 > 开始监控”。
7. 结束时选择“监控 > 停止监控”。需要保留数据时，选择“监控 > 保存监控数据”，按通知中的路径查找 CSV 文件。
8. 按 Ctrl+S 保存工程和窗口布局，然后选择“设备 > 断开设备”。

窗口没有数据显示时，分别检查“监控变量”中的“是否监控”和窗口内的显示选择。

## 3. 工程和工作界面

工程文件为 .uhprj。使用“文件 > 保存”或 Ctrl+S 保存当前工程；使用“文件 > 另存为”保存到新位置。窗口位置、标签页和窗口显示选择调整后，也要保存工程。设置窗口中的修改会自动保存到当前工程，关闭设置窗口不会撤销修改。

工程保存设置和窗口布局，不保存完整监控历史，也不包含外部符号文件或升级文件。需要留存监控数据时，另行导出 CSV；需要留存参数时，另行保存参数文件。

建议把工程、符号文件和升级文件放在同一文件夹或其子文件夹。搬移工程时一起复制这些文件，并在新位置检查文件能否正常打开。“另存为”不会复制外部文件。

打开旧工程时，如程序提示需要转换，请先确认原工程引用的固件文件仍可访问，再按提示操作。转换成功后，原文件旁会保留备份。遇到无法转换的提示，请保留原工程并联系软件提供方。

右键标签页可以添加或重命名标签页；各窗口可调整位置和大小。需要重新整理界面时，可选择“关于 > 重置窗口布局”。此操作会清除当前窗口布局和显示选择，建议先“另存为”备份工程。

## 4. 设备和通信设置

在“设置 > 设备”中选择 UDP 或 Serial，按设备提供方给出的值填写设备 ID。点击“添加固件”选择与设备当前固件匹配的符号文件。设备固件更新后，先停止监控并断开设备，再添加新符号文件，点击“更新固件变量”或选择“文件 > 重载符号表”；完成后检查监控和标定变量。

在“设置 > 通信”中按现场参数填写：

| 方式 | 需要核对的设置 |
| --- | --- |
| UDP | 本地 IP、远程 IP、XCP 端口；在线升级还需核对 IAP 端口。连接实际设备时不要沿用本机地址 127.0.0.1 |
| 串口 | COM 口、波特率、校验位、停止位、物理双工方式；半双工还需按适配器要求设置方向控制 |

串口适配器插入后可点击“刷新”重新选择 COM 口。超时时间和重试次数通常保持初始值；反复超时时，先核对设备供电、线缆及通信参数，再向设备提供方确认是否需要调整。

设置完成后选择“设备 > 连接设备”，等待成功通知。需要核对设备信息时选择“设备 > 设备信息”。操作结束后先停止监控，再选择“设备 > 断开设备”。通信设置不可修改时，先断开设备或等待升级结束。

## 5. 数据监控

### 设置变量和窗口

1. 选择“监控 > 监控设置”，在“符号表”中搜索变量，点击加号加入“监控变量”。
2. 在“监控变量”中核对类型；如需选择数组元素或指定偏移，在“偏移 / 下标”单元格中设置。无法确认类型或偏移时，先向设备提供方核对。
3. 勾选需要采集的变量的“是否监控”。可按需填写别名和单位。
4. 从“监控”菜单新建表格、曲线或位监控窗口。点击窗口内加号，勾选要在该窗口显示的变量。

“是否监控”控制采集，窗口内的勾选控制显示。一个变量可以显示在多个窗口中；从窗口移除变量不会取消采集。

“记录数据长度”表示每个变量保留的采样点数，并非记录时间。修改后点击“应用”会清除已有历史数据；需要保留时，先停止监控并导出。

### 采集、查看和导出

连接设备后选择“监控 > 开始监控”，结束时选择“监控 > 停止监控”。每次重新开始都会清空上一轮历史，开始前先导出需要保留的数据。调整采集变量、类型或偏移时，先停止监控并断开设备。

- **表格监控**：查看当前数值。表格中的数值不能直接用于修改设备；写入设备请使用标定窗口。
- **曲线监控**：查看变化趋势。用左键拖动平移、滚轮缩放；需要检查局部波形时，关闭“坐标自适应”，避免新数据到来后视图自动恢复。曲线横轴是采样点位置，不是时间。
- **位监控**：查看状态字的各位状态，可为各位填写别名。

更多曲线测量、缩放和键鼠操作见“关于 > 快捷键”。

停止监控后选择“监控 > 保存监控数据”。程序将本轮保留的数据保存为工程目录中的 data_日期_时间.csv；以成功通知中的完整路径为准。工程保存不代替数据导出。查看 CSV 可使用表格软件；“监控 > 读取监控数据”目前不可用于打开文件。

## 6. 参数标定

“回传”或“上传”是从设备读取到上位机；“下发”或“下载”是将上位机的值写入设备。

1. 选择“标定 > 标定设置”，在“符号表”中搜索变量并点击加号。
2. 在“标定变量”中核对类型及“偏移 / 下标”，按设备要求设置最小值和最大值。
3. 选择“标定 > 新建标定窗口”，点击窗口内加号，勾选要操作的变量。
4. 连接设备后，先选择“标定 > 参数回传”读取当前值。每次新连接都应重新回传，不能把空白显示当作设备值。
5. 在标定窗口“值”列输入目标值，确认变量、数值和单位。选中一行后按 Enter，或右键选择“下载至设备”。
6. 等待结果通知，再从设备读回，核对实际值。

“标定 > 参数下发”会处理工程中所有值非空的标定变量，包括未显示在当前窗口中的变量。使用前逐项检查；如中途通信失败，已写入的值不会自动恢复，应重新回传核对。设备断电后是否保留新值，请向设备提供方确认。

需要备份参数时，先回传当前值，再选择“标定 > 保存参数”，到工程目录查找 parameters_日期_时间.json。选择“标定 > 读取参数”只会将文件中的值填入上位机；核对后还需下发，设备值才会改变。

## 7. 用户指令

1. 向设备提供方确认指令码的用途。
2. 在“设置 > 指令”中填写指令名称和描述。
3. 点击顶部“新建指令窗口”图标，在窗口内点击加号选择指令。
4. 连接设备后，点击对应行的“执行”，查看结果通知。

## 8. 在线升级

升级前向设备提供方确认 .bin 文件适用于目标设备，并核对设备 ID、通信方式及参数。串口升级前先断开设备连接；升级期间保持供电和通信稳定。

1. 选择“设备 > 在线升级”，点击“选择文件”选取 .bin。
2. 再次核对目标设备和文件，点击“开始升级”。
3. 等待显示“升级完成”并达到 100%。某个中间阶段达到 100% 不表示升级已完成。
4. 升级后重新连接设备。若设备固件已更换，加载对应的符号文件并检查监控、标定变量。

需要中止时点击“取消”，等待取消提示及按钮恢复。升级取消或失败后，设备可能无法正常运行；按设备提供方的恢复流程处理。提示超时时，先核对文件、连接和设置，再请设备提供方协助。

## 9. 获取故障录波

1. 加载与设备当前固件匹配的符号文件，连接设备，并确认设备已完成一轮录波。
2. 选择“设备 > 故障录波”，点击“开始”。
3. 等待“录波完成”通知，按通知路径查找 fault_日期_时间.csv。

提示“录波未完成”时，等待设备完成录波后重试。其他读取失败提示可连同日志交给设备提供方排查。

## 10. 输出文件和日志

| 文件 | 位置 | 用途 |
| --- | --- | --- |
| .uhprj | 新建或另存为时选择的位置 | 工程设置和窗口布局 |
| data_日期_时间.csv | 工程目录 | 导出的监控数据 |
| parameters_日期_时间.json | 工程目录 | 保存的标定值 |
| fault_日期_时间.csv | 工程目录 | 上传的故障录波 |
| 日志文件 | 工程目录 | 查找操作和错误记录 |

需要保存日志时，在“设置 > 日志”开启“日志开关”和“保存至文件”，记录等级通常选 Information。需要长期保留日志时，及时复制到备份位置。

选择“文件 > 日志查看器”可查看日志；无需先打开工程。点击“打开目录”查看一个目录中的日志，或点击“打开文件”选择单个日志文件。在“最低日志等级”“来源模块”和时间条件中筛选；找不到记录时点击“清空筛选”。勾选“跟随最新”可查看不断新增的记录；点击一条记录可查看详情并复制。

反馈问题时，请提供程序版本、工程、通信方式、操作步骤、出错通知及对应时间段的日志。

## 11. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 菜单或“连接设备”不可用 | 先新建或打开工程；如正在升级，等待操作结束 |
| 连接超时或端口打开失败 | 检查设备供电、线缆、IP 与端口或 COM 口及串口参数；UDP 还需检查防火墙 |
| 半双工串口无法连接监控 | 半双工串口只用于在线升级；监控和标定请使用设备支持的 UDP 或全双工串口 |
| 找不到变量 | 检查符号文件是否与设备当前固件匹配，必要时重新加载 |
| 窗口没有数据 | 确认已连接并开始监控，同时检查采集勾选和窗口显示选择 |
| 曲线缩放后恢复原范围 | 关闭“坐标自适应”后再缩放 |
| 上一轮监控数据消失 | 重新开始监控或应用新的记录长度前，先停止并导出数据 |
| 标定值为空或写入后不确定结果 | 重新回传；写入前核对数值，写入后再读回确认 |
| 读取参数文件后设备值没变 | 读取只填入上位机，检查后还需下发 |
| 在线升级停止 | 核对升级文件、目标设备和通信参数，按通知排查；必要时联系设备提供方 |
