# UniversalHost 使用说明

本说明面向使用上位机进行设备调试、数据观察、参数标定和固件升级的操作人员。菜单名称以程序中文界面为准；例如“监控 > 开始监控”表示依次打开对应菜单。

可从“关于 > 使用说明”打开说明窗口，点击左侧目录查找对应操作。完整键鼠操作可从“关于 > 快捷键”打开。两份说明都可离线阅读。

## 1. 开始使用前

### 1.1 准备材料

- 发布包：保留 `UniversalHost.exe` 及随包提供的其他文件，在有写入权限的目录中存放工程和输出数据。
- 设备与通信连接：设备须支持本工具使用的 XCP 或自定义 IAP 协议。普通串口设备或网络设备不能仅凭接口相同直接接入。
- 设备连接参数：向设备提供方确认 IP、端口或串口参数，以及设备 ID。
- 符号表：准备与设备当前运行固件**同次构建**的 `.elf`、`.axf` 或 `.out`，支持 ARM ELF 与 TI C28x COFF/EABI。按文件头识别格式，文件名相同不代表固件版本相同。
- 升级文件：需要在线升级时，另外准备适用于目标设备的 `.bin` 文件。固件符号文件（`.elf`、`.axf`、`.out`）用于变量定位，BIN 用于升级，不能互相替代。

### 1.2 通信方式与可用功能

| 通信方式 | 连接设备、监控、标定、指令及录波上传 | 在线升级 |
| --- | --- | --- |
| UDP | 设备支持 XCP 时可用 | 设备支持自定义 IAP 时可用 |
| 全双工串口 `FullDuplex` | 设备支持串口 XCP 时可用 | 设备支持串口 IAP 时可用 |
| 半双工串口 `HalfDuplex`，如两线 RS485 | 不支持 XCP 连接 | 支持 IAP，须正确设置换向方式 |

参数写入和固件升级会改变设备状态。操作前确认目标设备、变量类型和文件版本，并按设备要求使其处于允许调试或升级的状态。固件升级期间保持供电和通信稳定。

## 2. 第一次监控的完整步骤

1. 启动 `UniversalHost.exe`，选择“文件 > 新建”，将工程保存为 `.uhprj`；也可以通过“文件 > 打开”选择已有工程。
2. 打开“设置 > 设备”，选择通信模式、填写设备 ID，点击“添加固件”加载与当前固件匹配的符号表。
3. 切换到“设置 > 通信”，填写 UDP 或串口参数。
4. 切换到“设置 > 监控”，在“符号表”中搜索根变量或已展开的成员，点击加号直接添加；在“监控变量”中核对类型，用同一单元格中的下拉选项和输入框设置偏移量或数组下标，然后勾选“是否监控”。
5. 选择“监控 > 新建表格监控窗口”或“新建曲线监控窗口”，点击窗口内加号，勾选要在该窗口显示的变量。
6. 选择“设备 > 连接设备”。收到“设备已连接”通知后，选择“监控 > 开始监控”，观察数值或曲线变化。
7. 结束本轮采集时选择“监控 > 停止监控”，再选择“监控 > 保存监控数据”。成功通知会给出 CSV 保存路径。
8. 按 `Ctrl+S` 保存工程和窗口布局，选择“设备 > 断开设备”。

如果窗口中没有变量，先检查第 4 步的采集勾选，再检查第 5 步的窗口显示选择。两个勾选用途不同，缺少其中一步就可能看不到数据。

## 3. 工程与工作界面

设置窗口中的设置即时生效，并自动保存到当前工程；关闭设置窗口不会撤销已经修改的设置。

窗口布局需要手动保存。调整窗口位置、大小、标签页或窗口显示选择后，使用“文件 > 保存”（`Ctrl+S`）保存布局。退出前保存工程，需要保留数据时先导出 CSV 或参数文件。

### 3.1 新建、打开和保存工程

工程文件扩展名为 `.uhprj`，保存设备与通信设置、符号与变量配置、指令说明、窗口布局和各窗口显示选择。工程不包含完整监控历史，也不把外部固件符号文件、升级 BIN 文件打包进去；监控数据和参数文件应单独保存。

程序 0.0.3 使用工程格式 2。打开含元数据的格式 1 工程时，程序自动调用随包的独立转换器，重新解析原工程引用的固件文件，并将符号转换为当前结构。转换不沿用旧的手动数值类型，按当前添加监控、标定变量的规则自动解析类型及访问地址：基本类型和固定成员解析成功后锁定类型、偏移量；数组使用元素类型并保留下标编辑能力。已保存的成员路径继续使用；没有路径时按新添加变量的默认访问生成，基本类型偏移归零，数组取各维起始下标。无法自动确定数值类型时设为 `Unknown`，允许重新配置。找不到根符号或符号匹配有歧义的监控、标定变量会被删除，同时清理窗口中的对应显示项，其余变量继续转换；完成后提示删除数量和明细，并说明各项删除原因。请先恢复原固件路径；缺少固件或解析失败时转换会中止并保留原工程。转换成功后，原工程旁会生成 `原文件名称_v1_yyyyMMdd_HHmmss_backup` 备份（时间为 UTC），原路径改为格式 2；原配置仍可在备份中找回。没有元数据的更早工程不支持转换，高于当前格式的工程须使用更新的程序。

打开当前格式工程只恢复保存的类型、偏移、路径、验证状态和访问快照，不重新解析固件，不删除变量，也不因加载而改写工程；外部固件文件缺失也不影响恢复配置。

| 操作 | 入口 | 使用说明 |
| --- | --- | --- |
| 新建工程 | 文件 > 新建 | 选择目录和文件名，创建空工程 |
| 打开工程 | 文件 > 打开 | 选择已有 `.uhprj`；切换工程前先断开设备 |
| 从 Windows 文件管理器打开工程 | 右键 `.uhprj` > 打开方式 > 选择其他应用 > 在这台电脑上查找其他应用 | 选择发布包中的 `UniversalHost.exe`，程序启动后直接加载该工程 |
| 保存工程 | 文件 > 保存，`Ctrl+S` | 保存当前设置、布局和窗口显示配置 |
| 另存为 | 文件 > 另存为，`Ctrl+Shift+S` | 保存到新位置，并切换到该工程路径 |
| 查看当前工程 | 主窗口标题；关于 > 当前工程 | 核对完整工程路径，避免操作错误工程 |

命令行也可指定工程路径：`UniversalHost.exe "D:\工程目录\示例.uhprj"`，或使用显式参数 `UniversalHost.exe --open "D:\工程目录\示例.uhprj"`。包含空格的路径应加引号；一次只打开一个工程。启动加载与“文件 > 打开”使用相同的工程版本转换和错误提示。

### 3.2 固件符号文件、升级 BIN 路径与工程搬移

建议将工程、对应固件符号文件和升级 BIN 放在同一工作目录或其子目录，添加固件和选择升级文件时从这里选取。手工填写升级文件路径时，可以填写完整路径，也可以填写从工程目录开始的路径，如 `firmware/APP.bin`。

搬移工程时一起复制这些文件并保持目录结构。工程外部的文件可能使用绝对路径，搬移后须检查是否仍可访问。“另存为”会调整文件引用以继续指向原文件，不会复制固件符号文件或升级 BIN。

### 3.3 窗口和标签页

- 从“监控”和“标定”菜单，或顶部图标按钮，新建所需窗口；新窗口加入当前标签页。
- 右键标签页可“添加标签页”或“重命名”，便于按任务组织多个工作页面。
- 各窗口可调整位置和大小；通过窗口内的下拉按钮选择显示列或显示项。
- 将鼠标停在图标按钮上可查看操作提示。通知用于反馈成功、失败和输出文件位置。
- 布局需要重新整理时，使用“关于 > 重置窗口布局”，再新建所需窗口。该操作会清除当前窗口布局和窗口显示配置，操作前可先另存为备份工程。

## 4. 设备、通信和符号表设置

### 4.1 设备设置

打开“设置”的“设备”选项卡，选择 `UDP` 或 `Serial` 通信模式，按设备提供方给出的值设置设备 ID，范围为 `0-255`。

点击“添加固件”选择 `.elf`、`.axf` 或 `.out`，允许添加多个不同文件。文件列表可右键查看已保存信息、复制路径、打开所在文件夹或删除文件；“符号表”可按名称、类型、地址和来源文件搜索。static/局部绑定变量在读取文件时过滤，不加入符号表。更新按唯一链接名称匹配，不依赖 C/C++ 编译文件名。

设备固件更新后，停止监控并断开设备，选择同次构建的符号文件，再点击“更新固件变量”或使用“文件 > 重载符号表”（`Ctrl+R`）。解析可取消；读取失败保留旧符号和配置。只有明确确认根变量或成员已删除、数组下标越界时才删除对应项，并汇总原因。信息缺失、格式不支持或匹配冲突不会作为删除依据。

存在可用 DWARF 时，自动解析类型和真实存储位宽并锁定类型选择。符号表显示 `Int8`、`结构体`、`联合体`、`Int8数组` 等类型；数组显示为 `符号名[长度]`，多维如 `matrix[2][3]`。结构体保留根项，同时直接列出 `结构体.成员`；点击加号直接添加。自动模式不支持位域和指针解引用。

“偏移量 / 数组下标”单元格内有下拉选项和输入框，数组默认选下标，结构体默认选偏移量，数值使用整数输入框并限制合法范围；多维数组在同一单元格内按维度从上到下分别输入。偏移相对于根变量，单位为**目标地址单位**：ARM 通常为 8 位，C28x 为 16 位。手动偏移与数组下标分别保存，不自动转换。UI 没有验证状态、编译单元及访问设置列；服务层继续执行安全检查。详细规则和限制见[固件变量解析](固件变量解析.md)。

### 4.2 UDP 设置

在“设置 > 通信”的 UDP 区域填写下列项目。出厂默认 IP 为 `127.0.0.1`，这是本机回环地址；连接实际网络设备时须按现场网络修改。

| 设置项 | 含义 | 初始值 |
| --- | --- | --- |
| 本地IP | 本机用于通信的网卡 IPv4 地址，可点击“刷新”更新列表 | `127.0.0.1` |
| 远程IP | 目标设备 IPv4 地址 | `127.0.0.1` |
| XCP本地端口 / XCP远程端口 | 本机接收端口 / 设备 XCP 端口 | `50010` / `50011` |
| IAP本地端口 / IAP远程端口 | 本机接收端口 / 设备 IAP 端口 | `50002` / `50001` |
| 超时时间 | 等待通信应答的时间，单位 ms | `50` |
| 重试次数 | IAP 普通应答超时后的最多重发次数 | `10` |

默认值只是初始配置，实际地址和端口以设备约定为准。确认本地 IP 属于当前使用的网卡、远程设备可达，且本地端口未被其他程序占用。连接或升级失败时，也应检查防火墙是否允许对应 UDP 通信。

### 4.3 串口设置

连接适配器后点击“刷新”，选择正确的 COM 口。串口数据位固定为 8 位；波特率、校验位和停止位必须与设备一致，初始配置为 `115200`、`None`、`One`。

| 设置项 | 操作要点 |
| --- | --- |
| 物理双工 | 全双工选 `FullDuplex`；两线半双工链路选 `HalfDuplex`。半双工仅能升级，不能连接 XCP |
| 方向控制 | 自动换向适配器选 `Automatic`；须用 RTS 控制时，按硬件要求选发送时高电平或低电平；全双工选 `Automatic` |
| 换向延时 | 半双工方向切换裕量，单位 ms，初始值 `2`；按适配器要求调整 |
| 适配器有本机回显 | 只有适配器确实回传发送的完整帧时才勾选；无回显时不要启用 |
| 超时时间 | 单位 ms，初始值 `50`；通常保持初始值，需调整时向设备提供方确认 |
| 重试次数 | IAP 普通应答超时后的最多重发次数，初始值 `10` |

设备须支持本工具的串口封装。无法通信时，应由设备提供方核对协议，不能只靠修改波特率解决。

### 4.4 连接和断开

1. 确认工程已打开、通信参数正确，选择“设备 > 连接设备”或顶部连接图标。
2. 等待“设备已连接”通知；需要核对设备信息时，选择“设备 > 设备信息”。
3. 按任务启动监控、读取标定值或执行其他操作。
4. 操作结束后停止监控，再选择“设备 > 断开设备”。

监控、标定和执行指令前需要先连接设备。在线升级可以直接打开升级工具，不必先点击“连接设备”。通信参数无法修改时，先断开设备或等待升级结束。

## 5. 数据监控

### 5.1 配置采集变量

1. 打开“监控 > 监控设置”，或切换到“设置”的“监控”选项卡。
2. 在“符号表”子选项卡搜索根变量或展开的成员，点击加号直接加入列表。
3. 切换到“监控变量”，核对类型；根结构体或明确编辑偏移量时需自行选择数值类型，如 `Int16`、`Uint32`、`Float32`。`Unknown` 或未通过内部验证的自动项会阻止开始监控。
4. 根据需要填写别名、单位和描述，并在“偏移量 / 数组下标”单元格选择输入方式。偏移必须由设备定义确认，不应按显示大小猜测。
5. 勾选实际需要采集的变量。“当前监控变量数”和“监控变量总大小”统计所有已勾选变量，不受搜索筛选影响。
6. 按需设置“记录数据长度”，点击“应用”。建议使用大于零的值；初始值为每个变量 `100000` 个点，上限为 `1000000` 个点。

记录长度表示点数，不是秒数。变量越多、记录长度越大，内存占用越高。点击“应用”会清除已有监控历史，需保留时先停止监控并导出。

### 5.2 选择窗口显示变量

监控设置中的“是否监控”决定设备采集哪些变量；窗口内加号打开的选择窗口决定该窗口显示哪些变量。显示列表只提供已勾选采集的变量。同一个变量可以同时显示在多个窗口中。

1. 从“监控”菜单新建表格、曲线或位监控窗口。
2. 点击该窗口的加号，在“变量选择窗口”勾选需要显示的变量，关闭选择窗口即可。
3. 从窗口右键菜单可添加、移除或清空显示变量。移除窗口显示不会取消该变量的采集勾选。

### 5.3 开始、停止和历史数据

连接设备后，选择“监控 > 开始监控”或顶部开始图标；结束时选择“监控 > 停止监控”。每次开始监控都会清空上一轮历史。停止后保留本轮数据，便于查看曲线和导出。

连接设备或监控运行时不能修改访问布局、类型、偏移、监控勾选状态或增删变量。监控列表中的别名、单位和描述仍可编辑，不会重建采集运行时或清空历史数据。需要调整采集配置时先停止监控并断开设备。

采样率由设备端配置。需要改变采样速度时，请联系设备提供方，修改“记录数据长度”不能改变采样速度。出现数据缺失时，可先减少采集变量，再请设备提供方检查采样设置和通信连接。

### 5.4 表格监控

表格监控适合观察变量当前值。通过窗口下拉按钮选择变量名、别名、值、单位等列，右键可复制变量名或变量值。该表格用于观察，修改设备值应使用标定窗口。

### 5.5 曲线监控

曲线监控适合观察变化趋势。点击左侧变量条目选择曲线；主键盘 `1-9` 可按当前列表顺序选中前九个变量。变量条目旁的色块或 `Space` 可切换显示和隐藏，隐藏曲线不会停止采集。

默认每条曲线使用自己的 Y 轴。点击窗口工具栏中的“共用Y轴”按钮（单轴双曲线图标）可切换为所有曲线共用一个 Y 轴，再次点击恢复独立 Y 轴。共用模式下，自动适应按所有可见曲线的整体范围计算。按住 `Y` 并左键拖动可平移所选变量使用的 Y 轴，按住 `Y` 并滚轮可缩放；共用模式下这些操作会同时影响所有曲线。普通左键拖动平移图表，滚轮缩放，图表右键菜单可保存图像、复制到剪贴板或自动适应坐标轴。

坐标自适应默认开启：收到新数据或重新开启自适应时，Y 轴适应已有数据，X 轴恢复为完整记录长度。手动检查局部细节时可用窗口自适应按钮或 `E` 关闭，避免下一次数据更新恢复范围；`Ctrl+E` 可统一切换所有曲线窗口。各窗口状态不一致时，统一切换会全部开启。

切换标签页后会恢复公共 X 轴范围、各曲线独立的 Y 轴范围、共用 Y 轴范围及当前选中曲线。按 `Ctrl+S` 保存工程时，同时保存这些范围、Y 轴共用模式、曲线颜色、显示状态和自适应开关；重新打开工程后恢复。工程不保存采样历史，自适应开启时新数据仍会更新坐标范围。修改记录长度会重设 X 轴为完整记录长度。

曲线横轴按采样点位置显示，不能直接当作秒数；换算时间须使用设备实际采样周期。历史未填满时只显示已采集点，填满后循环覆盖旧数据并以扫描线指示更新位置。要长期留存数据，应及时停止并导出。

| 测量方式 | 窗口快捷键 | 使用方法 |
| --- | --- | --- |
| 鼠标坐标 | `X` | 在图表中移动鼠标，查看当前坐标 |
| 曲线上最近点 | `C` | 先选曲线，再将鼠标移到曲线附近，查看最近采样点 |
| 垂直双光标 | `V` | 拖动 A、B 光标，底部显示坐标及 `B-A` 差值 |
| 水平双光标 | `B` | 拖动 A、B 光标，观察所选曲线的纵向差值 |

以上测量方式互斥，重复按同一快捷键可关闭。光标移出视野后可通过边缘标记拖回。窗口局部快捷键要求焦点位于对应窗口；完整图表键鼠操作见“关于 > 快捷键”。

### 5.6 位监控

位监控按变量类型的位宽显示各位状态，适合查看状态字和标志位。每列最多 16 位，8 位变量显示一列 8 位；可展开变量并为各位填写别名。类型必须与设备定义一致，通常选择相应无符号整数类型。

### 5.7 导出监控数据

停止监控后选择“监控 > 保存监控数据”，将本轮保留的数据导出到工程所在目录，文件名形如 `data_20261010_143000.csv`。首行为变量名及可用别名，后续各行为采样值；以成功通知给出的完整路径为准。

导出范围是已采集变量，不局限于当前窗口显示的曲线。CSV 不含独立的时间戳列，历史为空时不能导出。工程保存不替代数据导出。

“监控 > 读取监控数据”目前不可用于打开文件；查看已导出的 CSV 时，请使用表格软件或其他分析工具。

## 6. 参数标定

标定是读取或写入设备变量。“上传”“回传”表示从设备读取到上位机；“下载”“下发”表示将上位机值写入设备。

### 6.1 配置标定变量

1. 打开“标定 > 标定设置”，在“符号表”中搜索变量并点击加号。
2. 点击加号直接添加根变量或展开的成员，切换到“标定变量”核对类型，在“偏移量 / 数组下标”单元格选择并输入。按需要填写别名、单位、描述。
3. 根据设备允许的范围设置最小值和最大值；留空表示没有设置该侧的用户限值。输入仍须满足所选数据类型的范围和格式。
4. 选择“标定 > 新建标定窗口”，点击窗口内加号，勾选本窗口需要操作的变量。

### 6.2 读取和写入

每次连接设备成功后，程序会清空标定值显示，避免显示上一次连接的旧值。连接不会自动读取参数，请主动执行“参数回传”或窗口上传操作。

1. 连接设备，先读取当前值，确认变量和设备对应关系。
2. 在标定窗口“值”列输入目标数值，完成单元格编辑，确认格式和上下限正确。
3. 选中该行，按 `Enter` 或右键“下载至设备”，写入当前变量。
4. 等待结果通知，再通过右键“从设备上传”读回，核对设备实际值。

| 操作入口 | 作用范围 |
| --- | --- |
| 标定 > 参数回传，`Ctrl+F` | 从设备读取工程全部标定变量 |
| 标定 > 参数下发，`Ctrl+D` | 预检查工程中值非空的全部标定变量，通过后下发；未知类型会拒绝整批 |
| 标定窗口上传 / 下载按钮 | 仅操作当前窗口显示的变量；有未知类型时会停止，下载前应填好待写入值 |
| 行右键“从设备上传” / “下载至设备”，`Enter` 下发 | 仅操作当前选中变量 |

全局批量下发包含其他窗口和未显示的标定变量。单变量、窗口批量和全局批量共用服务层保护；整批类型、地址、边界、数值和写入区间检查通过后才发送第一项。重叠的联合体成员不能同批下发，不同来源文件也不能绕过重叠检查。预检查失败时本批零写入；通信中途失败时，已经成功写入的变量不会自动恢复，应读回确认。

写入参数后，如需关机后仍保留这些值，请向设备提供方确认是否需要额外的保存操作。

### 6.3 保存和读取参数文件

“标定 > 保存参数”将非空的标定值写入工程目录，文件名形如 `parameters_20261010_143000.json`。建议先从设备回传再保存，获得当前设备参数备份。

选择“标定 > 读取参数”，打开以前保存的参数文件。请使用保存该参数文件时的工程，或由该工程“另存为”得到的副本。读取后先检查各行数值，再按需要下发设备，并重新读回核对。仅打开参数文件不会修改设备中的值。

## 7. 用户指令

用户指令用于执行设备固件定义的动作。指令码的含义应向设备提供方确认，上位机填写名称或描述不会改变设备端行为。

1. 在“设置 > 指令”中，为需要使用的指令码填写名称和描述；列表可搜索指令码、名称、描述。
2. 点击顶部“新建指令窗口”图标，再点击窗口加号，选择需要显示的指令。
3. 连接设备后，点击对应行的“执行”按钮，查看成功或失败通知。

指令窗口中移除或清空显示条目，不会删除设备端指令。未知用途的指令应先确认含义再执行。

## 8. 在线升级固件

### 8.1 升级前检查

向设备提供方确认 BIN 适用于目标型号和硬件版本，再选择升级文件。文件能够打开并不表示它适用于当前设备。

串口升级必须断开 XCP 设备连接。检查“设置 > 设备”的通信模式和设备 ID，以及“设置 > 通信”中的串口参数或 IAP 专用 UDP 端口。

在“设置 > IAP”可选择升级文件，并设置各阶段的超时时间，单位为秒。初始值为握手 `5`、擦除 `10`、写入 `10`、校验 `10`、重启 `30`。通常先使用初始值；反复提示超时时，请先向设备提供方核对通信设置和等待时间，再调整。

### 8.2 执行升级

1. 选择“设备 > 在线升级”，打开升级工具窗口。
2. 点击“选择文件”选取 BIN，也可以填写绝对路径或相对工程目录的路径。
3. 确认目标设备、文件和通信配置，再点击“开始升级”。
4. 观察阶段文字和进度条，升级期间保持设备供电和通信稳定。
5. 等待显示“升级完成”并达到 `100%`。仅看到某一阶段达到 `100%` 时，仍需继续等待最终结果。
6. 升级后重新连接设备；固件地址有变化时，加载对应的新固件符号文件，检查监控和标定配置。

### 8.3 取消与失败

需要中止时点击“取消”，等待显示“升级取消”且操作按钮恢复后，再连接设备或重新升级。

取消或失败不会恢复已擦除或已写入的固件。设备可能仍停留在升级程序中，应按设备提供方的恢复流程处理。显示“升级停止”时，根据通知定位文件、超时、设备返回的失败或通信问题；例如 ROM 长度过长提示通常需要核对所选 BIN。

## 9. 获取故障录波

故障录波用于读取设备已经完成的录波数据，不是启动实时监控，也不是在上位机触发设备故障。

1. 加载与设备固件匹配的固件符号文件，确认符号表包含 `fault_recorder_state` 和 `recorder_data`。这两个符号不必另外勾选为监控变量。
2. 连接设备，确认设备已经完成一轮故障录波；是否完成由设备端状态决定。
3. 选择“设备 > 故障录波”，点击工具窗口中的“开始”。
4. 等待录波状态、通道信息和各通道数据上传。完成后显示“录波完成”，进度为 `100%`，通知给出保存路径。
5. 在工程目录查看 `fault_日期_时间.csv`，使用表格或分析软件读取；每列对应一个通道，各行按采样先后顺序排列。

提示“录波未完成”时先等待设备完成录波，再重新操作。读取失败时，核对固件符号文件是否与当前固件匹配，并将通知内容和日志交给设备提供方排查。

## 10. 输出文件与日志

| 文件 | 默认位置 | 内容 |
| --- | --- | --- |
| `.uhprj` | 新建或另存为时选择的路径 | 工程配置、窗口布局和显示选择 |
| `data_日期_时间.csv` | 工程所在目录 | 本轮保留的监控数据 |
| `parameters_日期_时间.json` | 工程所在目录 | 非空标定值备份 |
| `fault_日期_时间.csv` | 工程所在目录 | 从设备上传的故障录波数据 |
| `log_日期.jsonl` 等日志文件 | 工程所在目录 | 通信、操作、标定和错误记录 |

需要保存操作记录时，在“设置 > 日志”勾选“日志开关”和“保存至文件”，记录等级通常选择 `Information`。技术人员需要更详细记录时，再按其要求临时改选 `Debug` 或 `Verbose`；问题复现后恢复原设置。

查找标定操作时，在日志查看器的“来源模块”中勾选 `Calibration`，再选择对应的时间范围，查看参数修改及参数文件读取、保存记录。需要保留标定历史时，记录等级使用 `Information`；选择 `Warning` 或更高等级时，不会保存这些普通操作记录。

日志会随日期和文件大小自动分成多个文件，只保留最近 31 个文件。需要长期留存时，请及时将日志文件复制到备份目录；“31 个文件”不代表“31 天”。

### 10.1 日志查看器

#### 打开日志

1. 选择“文件 > 日志查看器”，不打开工程也可以使用。
2. 查看某个目录的日志时，点击“打开目录”，再从左侧文件列表选择日志；查看单个文件时，点击“打开文件”选择 `.jsonl` 日志。
3. 在右侧查看时间、等级、来源模块和消息。橙色 `Warning` 表示警告，红色 `Error`、`Fatal` 表示错误，应优先查看。

打开查看器时，如果主窗口已有工程，会自动打开工程目录中的最新日志。再次点击“文件 > 日志查看器”会回到已有窗口，保留当前查看内容。切换主窗口工程后，查看器仍显示原先的日志；需要查看新工程日志时，请重新选择目录。关闭查看器后再次打开，会按当时的工程重新选择目录。

#### 查找需要的记录

1. 在“最低日志等级”选择需要的等级。选择 `Information` 会同时显示 `Information`、`Warning`、`Error`、`Fatal`；选择“全部”可查看所有等级。
2. 在“来源模块”勾选需要查看的模块，可以勾选多个；全部不勾选时显示所有模块。
3. 需要限定时间时，勾选“开始时间”或“结束时间”，再选择日期和时间；不勾选的一侧表示不限。先核对界面提示的日志时区，例如 `UTC+08:00`，所选时间应与日志中的时间对应；日志时区可能与电脑时区不同。列表时间显示到毫秒。
4. 同时设置等级、模块和时间时，只显示符合这些条件的记录。找不到记录时，可点击“清空筛选”后重新选择。

开始和结束时刻都包含在结果中，结束时间包含所选秒内的全部记录。提示开始时间晚于结束时间时，请重新选择；修改正确前，仍按上一次有效时间范围显示。

#### 查看新日志或浏览历史

| 操作 | 使用方法 |
| --- | --- |
| 自动查看新记录 | 勾选“自动刷新”，约每秒更新一次 |
| 跟到最新位置 | 勾选“跟随最新”，会同时开启自动刷新，并跳到最新记录；打开的是目录时，也会自动切换到新生成的日志文件 |
| 停留查看已有内容 | 取消“自动刷新”，同时会取消“跟随最新”；仍可筛选和复制内容 |
| 更新一次 | 点击“手动刷新”，更新当前文件和目录列表 |
| 恢复更新当前文件 | 重新勾选“自动刷新”，会补上这期间当前文件新增的记录；如需同时跳到最新位置，再勾选“跟随最新” |

向上浏览或手动选择其他日志文件时，会取消“跟随最新”，自动刷新仍保持开启。需要恢复跟随时，重新勾选即可；筛选条件会保留。

如果停止更新期间生成了多个新日志文件，勾选“跟随最新”会直接打开最新文件。要查看之前的记录，请在左侧依次选择对应文件。通过“打开文件”选择单个日志时，跟随只更新该文件；需要自动切换新文件时，改用“打开目录”。

#### 查看和复制详情

点击一条日志，在下方查看完整消息、错误原因及其他信息。选中文本后按 `Ctrl+C` 可复制所选部分；点击“复制完整内容”可复制整条详情。需要将原始记录交给技术人员时，点击“复制原始 JSON”。

#### 遇到提示时怎么处理

| 提示或现象 | 操作方法 |
| --- | --- |
| 没有日志文件或文件为空 | 核对目录和文件；需要本程序生成新日志时，先打开工程，再在“设置 > 日志”开启保存 |
| 筛选后没有记录 | 点击“清空筛选”，再核对日志文件、时间范围和来源模块 |
| 文件被删除、移动或无法读取 | 重新选择文件；确认仍有访问权限，必要时联系文件管理人员 |
| 有跳过的记录 | 部分记录无法显示，保留原始日志并交给技术人员检查 |
| 查看不到更早的内容 | 先选择对应日期的日志文件；日志很多时，查看器只保留最近一部分，具体范围见窗口底部，需要进一步查阅时请保留原文件并联系技术人员 |

查看、筛选和复制日志不会修改原文件，也不会影响主程序继续记录日志。

反馈问题时提供程序版本（“关于”菜单中查看）、使用的工程、通信方式、操作步骤、出错通知及对应时间段的日志。涉及文件引用时，同时提供匹配的固件符号文件或升级 BIN 版本信息。

## 11. 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 大部分菜单不可用 | 先新建或打开工程；连接、监控和升级状态也会影响按钮是否可用 |
| “连接设备”不可用 | 先打开工程；已连接时无需重复连接，正在升级时先等待升级结束 |
| 连接超时或端口打开失败 | UDP 检查网卡、IP、XCP 端口、防火墙和设备供电；串口检查 COM、占用情况、波特率、校验和停止位 |
| 半双工串口连接被拒绝 | 当前只支持 IAP；需要监控或标定时使用设备支持的 UDP 或全双工链路 |
| 设置中的通信参数不能修改 | 先断开设备；正在升级时，等待升级结束且按钮恢复后再修改 |
| 导入固件失败或找不到变量 | 确认是受支持的 ELF/TI COFF、路径可访问且文件含有所需符号；核对运行固件版本及随包 `dependencies/symbol-tools` 文件 |
| “变量选择窗口”中没有变量 | 先在监控设置中添加变量并勾选“是否监控”，或在标定设置中添加标定变量 |
| 提示类型为 `Unknown` 或自动项未验证 | 主动更新带类型信息的匹配固件，查看原因；需要自行指定时明确改为手动模式 |
| 窗口无数值或曲线不更新 | 确认已连接、已开始监控、采集勾选和窗口显示选择正确；再检查设备是否在发送采样数据 |
| 曲线缩放后又恢复 | 关闭坐标自适应，再手动缩放和平移 |
| 重新开始后旧数据消失 | 每次开始监控会清空历史，记录长度应用也会清空；下次开始前先停止并导出 |
| 保存监控数据提示历史为空 | 先成功采集数据，再停止并保存；仅加载工程不会恢复监控历史 |
| 标定连接后值为空 | 这是新连接清理旧显示值的正常行为，主动执行参数回传 |
| 标定写入失败或数值异常 | 检查类型、数值格式、上下限、偏移量以及固件符号文件与设备固件匹配情况，读回核对设备实际值 |
| 读取参数文件后设备值没变 | 读取只填写上位机值，检查后仍需下发；未匹配的工程变量不会被填入 |
| 故障录波提示未完成 | 等待设备端录波完成后再上传；同时确认必需符号存在 |
| 在线升级停止 | 核对 BIN 和设备 ID、IAP 通信参数、阶段超时及错误通知；串口升级前断开 XCP |
| 工程搬移后固件符号文件或升级 BIN 无法读取 | 将引用文件一起搬移并保留相对目录，或重新选择文件路径 |
| 内置说明与当前操作不一致 | 在“关于”中核对程序版本，并向软件提供方确认是否需要更新发布包 |
