# 快捷键

## 全局快捷键

### 文件

| 操作 | 快捷键 |
| --- | --- |
| 保存 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |
| 重载符号表 | `Ctrl+R` |
| 设置 | `Ctrl+,` |

### 标定

| 操作 | 快捷键 |
| --- | --- |
| 下发 | `Ctrl+D` |
| 上传 | `Ctrl+F` |

### 监控

| 操作 | 快捷键 |
| --- | --- |
| 切换所有窗口坐标自适应 | `Ctrl+E` |

## 窗口局部快捷键

使用局部自定义快捷键时，焦点需要位于对应窗口或表格内。ScottPlot 的键鼠操作要求鼠标指针位于图表区域，键盘操作不要求图表获得焦点。

### 曲线监控窗口

#### 自定义快捷键

| 操作 | 快捷键 |
| --- | --- |
| 按当前列表顺序选中第 1–9 个变量；变量数量不足时保持原选择 | 主键盘 `1`–`9`（不含小键盘） |
| 切换选中曲线的显示 / 隐藏 | `Space` |
| 切换当前窗口的坐标自适应（Y 轴自动适应，X 轴恢复最大记录长度） | `E` |
| 切换鼠标坐标测量 | `X` |
| 切换所选曲线最近点坐标测量 | `C` |
| 切换垂直光标测量 | `V` |
| 切换水平光标测量 | `B` |
| 平移所选变量的 Y 轴 | 按住 `Y` 并用鼠标左键拖动 |
| 缩放所选变量的 Y 轴 | 按住 `Y` 并滚动鼠标滚轮 |

#### ScottPlot 默认快捷键

##### 键盘

| 按键 | 默认操作 |
| --- | --- |
| `←`、`↑`、`→`、`↓` | 向对应方向平移图表 |
| `Shift` 或 `Alt` + 方向键 | 改变平移步长 |
| `Ctrl` + 方向键 | 缩放图表 |
| `A` | 自动调整坐标轴范围（AutoScale） |

##### 鼠标

| 操作 | 默认功能 |
| --- | --- |
| 左键拖动 | 平移 |
| 右键拖动 | 缩放 |
| 滚轮 | 以鼠标位置为中心缩放 |
| 中键单击 | 自动调整坐标轴范围 |
| 中键拖动 | 框选区域并放大 |
| `Alt` + 左键拖动 | 框选区域并放大 |
| 右键单击 | 打开右键菜单 |
| 左键双击 | 运行 Benchmark |
| `Ctrl` + 左键拖动 | X 轴平移 |
| `Ctrl` + 滚轮 / 右键拖动 | X 轴缩放 |
| `Shift` + 左键拖动 | Y 轴平移 |
| `Shift` + 滚轮 / 右键拖动 | Y 轴缩放 |

### 表格标定窗口

| 操作 | 快捷键 |
| --- | --- |
