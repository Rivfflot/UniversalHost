# 快捷键

按窗口查找操作。使用局部快捷键前，请先单击对应窗口或表格。表内的“移除”均指从当前窗口移除。

## 全局快捷键

在主窗口内使用，对应功能可用时生效。

| 操作 | 快捷键 |
| --- | --- |
| 保存项目 | `Ctrl+S` |
| 重载符号表 | `Ctrl+R` |
| 打开设置 | `Ctrl+,` |
| 打开日志查看器 | `Ctrl+L` |
| 下发标定值至设备 | `Ctrl+D` |
| 从设备上传标定值 | `Ctrl+F` |
| 切换全部曲线窗口自适应 | `Ctrl+E` |

`Ctrl+E`：全部曲线窗口已开启自适应时统一关闭，否则统一开启。

## 曲线监控窗口

### 变量与测量

单击曲线监控窗口后，可使用以下快捷键。

| 操作 | 快捷键 |
| --- | --- |
| 选中第 1–9 个变量 | 主键盘 `1`–`9` |
| 移除所选变量 | `Delete` |
| 显示 / 隐藏所选曲线 | `Space` |
| 开启 / 关闭持续自适应 | `E` |
| 切换鼠标坐标测量 | `X` |
| 切换所选曲线最近点测量 | `C` |
| 切换垂直光标测量 | `V` |
| 切换水平光标测量 | `B` |

数字键按当前变量列表顺序选择，不含小键盘。超出变量数量时保留原选择。

### 图表键盘操作

将鼠标指针移至曲线图区域后使用。

方向键指 `←`、`↑`、`→`、`↓`。

| 操作 | 快捷键 |
| --- | --- |
| 按方向平移图表 | 方向键 |
| 改变平移步长 | `Shift` + 方向键 |
| 改变平移步长 | `Alt` + 方向键 |
| 缩放图表 | `Ctrl` + 方向键 |
| 单次自适应 X、Y 轴 | `A` |

- `E` 控制当前窗口的持续自适应：Y 轴随数据自动调整，X 轴显示完整记录长度。
- `A` 或中键单击仅调整一次 X、Y 轴，使其容纳当前数据，不改变持续自适应开关。
- 持续自适应开启时，后续数据更新仍会自动调整 Y 轴，并将 X 轴恢复为完整记录长度。

### 图表鼠标操作

在曲线图区域内操作。使用 `Y` 组合操作前，先在当前窗口的变量列表中选中变量，并在操作时按住 `Y`。

| 操作 | 鼠标操作 |
| --- | --- |
| 平移所选变量 Y 轴 | `Y` + 左键拖动 |
| 缩放所选变量 Y 轴 | `Y` + 滚轮 |
| 平移图表 | 左键拖动 |
| 缩放图表 | 右键拖动 |
| 以鼠标位置为中心缩放 | 滚轮 |
| 单次自适应 X、Y 轴 | 中键单击 |
| 框选区域并放大 | 中键拖动 |
| 框选区域并放大 | `Alt` + 左键拖动 |
| 打开右键菜单 | 右键单击 |
| 运行图表性能测试 | 左键双击 |
| X 轴平移 | `Ctrl` + 左键拖动 |
| X 轴缩放 | `Ctrl` + 滚轮 / 右键拖动 |
| Y 轴平移 | `Shift` + 左键拖动 |
| Y 轴缩放 | `Shift` + 滚轮 / 右键拖动 |

## 表格标定窗口

先在表格中选中变量，再执行操作。

| 操作 | 快捷键 |
| --- | --- |
| 移除所选变量 | `Delete` |
| 从设备上传所选变量值 | `U` |
| 下发所选变量值至设备 | `D` 或 `Enter` |

## 表格监控窗口

| --- | --- |
| 移除所选变量 | `Delete` |
