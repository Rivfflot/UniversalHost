# 快捷键

## 文件

| 操作 | 快捷键 |
| --- | --- |
| 保存 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |
| 重载符号表 | `Ctrl+R` |
| 设置 | `Ctrl+,` |

## 标定

| 操作 | 快捷键 |
| --- | --- |
| 下发 | `Ctrl+D` |
| 上传 | `Ctrl+F` |

## 监控

| 操作 | 快捷键 |
| --- | --- |
| 切换所有窗口坐标自适应 | `Ctrl+E` |

## 局部操作

焦点需要在对应窗口或表格内。

| 焦点所在区域 | 操作 | 快捷键 |
| --- | --- | --- |
| 曲线监控窗口 | 切换选中曲线的显示 / 隐藏 | `Space` |
| 曲线监控窗口 | 切换当前窗口的坐标自适应（Y 轴自动适应，X 轴恢复最大记录长度） | `E` |
| 曲线监控窗口 | 切换鼠标坐标测量 | `X` |
| 曲线监控窗口 | 切换所选曲线最近点坐标测量 | `C` |
| 曲线监控窗口 | 切换垂直光标测量 | `V` |
| 曲线监控窗口 | 切换水平光标测量 | `B` |
| 曲线监控窗口 | 平移所选变量的 Y 轴 | `Y` + 鼠标左键拖动 |
| 曲线监控窗口 | 缩放所选变量的 Y 轴 | `Y` + 鼠标滚轮 |
| 标定表格 | 下发当前选中变量至设备 | `Enter` |

## ScottPlot 图表区域

操作时鼠标指针需要在图表区域，焦点无要求。

### 键盘

| 按键 | 默认操作 |
| --- | --- |
| `←`、`↑`、`→`、`↓` | 向对应方向平移图表 |
| `Shift` 或 `Alt` + 方向键 | 改变平移步长 |
| `Ctrl` + 方向键 | 缩放图表 |
| `A` | 自动调整坐标轴范围（AutoScale） |

### 鼠标

| 操作 | 默认功能 |
| --- | --- |
| 左键拖动 | 平移 |
| 右键拖动 | 缩放 |
| 滚轮 | 以鼠标位置为中心缩放 |
| 中键单击 | 自动调整坐标轴范围 |
| 中键拖动 | 框选区域并放大 |
| `Alt` + 左键拖动 | 框选区域并放大 |
| 右键单击 | 打开右键菜单 |
| 左键双击 | 运行 Benchmark |
| `Ctrl` + 左键拖动 | X 轴平移 |
| `Ctrl` + 滚轮/右键拖动 | X 轴缩放 |
| `Shift` + 左键拖动 | Y 轴平移 |
| `Shift` + 滚轮/右键拖动 | Y 轴缩放 |

## OEM 按键名称对照

便于查找绑定。

| 物理符号 | 对应的物理按键含义 | C# 代码中的枚举（Key） | XAML / 字符串写法 |
| --- | --- | --- | --- |
| `,` | 逗号 | `Key.OemComma` | `OemComma` |
| `.` | 句号 | `Key.OemPeriod` | `OemPeriod` |
| `/` | 斜杠 | `Key.OemQuestion`（因为与问号共用一键） | `OemQuestion` |
| `;` | 分号 | `Key.OemSemicolon` | `OemSemicolon` |
| `'` | 单引号 | `Key.OemQuotes` | `OemQuotes` |
| `[` | 左中括号 | `Key.OemOpenBrackets` | `OemOpenBrackets` |
| `]` | 右中括号 | `Key.OemCloseBrackets` | `OemCloseBrackets` |
| `-` | 减号 / 破折号 | `Key.OemMinus` | `OemMinus` |
| `=` | 等于号 / 加号 | `Key.OemPlus` | `OemPlus` |
| `` ` `` | 反引号 / 波浪号 | `Key.OemTilde` | `OemTilde` |
| `\` | 反斜杠 | `Key.OemPipe` | `OemPipe` |
